计算公式（简）

VRAM 需求
VRAM = 权重字节 + KV cache + 框架开销

权重按档位字节（fp16 2B · Q4 0.5B）计算，KV 随上下文与架构伸缩，框架开销 0.75 GB。

速度预测
tok/s ≈ min(带宽约束, 算力约束)

LLM 以显存带宽为主，图像以算力为主；解析公式估算，不采实测数据。

工程常量
带宽利用率 0.8 系统预留 0.5 GB 最小余量 1 GB 默认上下文 8K 图像 FLOPs 系数 1200

附加规则

  • 放得下但显存余量 < 1 GB → 强制降为「勉强」，防 OOM 抖动。
  • 可用显存 = 显存 − 0.5 GB 系统预留（CUDA context + 引擎常驻）。
  • 无官方量化自动降级到最轻可用档；自定义显存只判容量，速度不可预估。
