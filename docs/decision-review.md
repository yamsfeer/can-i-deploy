# Can I Deploy — 决策回顾

> 本文档是需求访谈（grilling）的问答简略回顾，记录关键问题与决策。详细设计见 `Docs/PRD.md`。

## Q1 差异化定位
**问**：现有同类工具（FitLLM、canirunthisllm、canitrun.dev、llmrun.dev、llm-speed 等）已覆盖 LLM VRAM/速度预测，本工具凭什么赢？
**答**：先做 **A 多模态覆盖 + B ModelScope 国产模型**；**C 纯 CPU 场景、D 反向推荐进 todo**；参考 llmrun.dev 的设计。

## Q2 工具形态
**问**：CLI / 静态站 / 本地 Web / 公开站点？
**答**：**Web 网站，前后端分离**，本地开发，开发完就地部署到自有服务器（已有服务器，域名以后定）。

## Q3 一期模型范围
**问**：多模态覆盖到哪？
**答**：一期 **LLM + VLM + 图像生成**（VLM 与 LLM 共用预测引擎）；**视频生成二期**；TTS/ASR、Embedding 进 todo。

## Q4 速度预测方法
**问**：纯公式 / 纯数据驱动 / 混合？
**答**：**纯解析公式**，不采真实实测数据，输出**4 档分级**（能跑/不错/勉强/放不下），给估量值即可。llmrun 速度列空白是本工具机会点。

## Q5 量化档位与引擎
**问**：量化档位和推理引擎覆盖到哪？
**答**：只做**最常见**的——LLM/VLM：**fp16 + GGUF Q8_0 / Q6_K / Q5_K_M / Q4_K_M**（砍 Q3/Q2）；图像生成：**fp16 + fp8**。引擎只做**最流行**的：本地统一按 **Ollama/llama.cpp 系**建模，图像按 **ComfyUI** 建模；vLLM 进 todo。

## Q6 硬件库范围
**问**：覆盖哪些硬件？
**答**：一期只做 **NVIDIA 物理卡 + 常见云实例映射**（30~50 型号手工维护规格表）；**AMD / Apple Silicon / 纯 CPU 进 todo**；**价格数据不做**（浮动大、参考价值少）。

## Q7 模型收录策略
**问**：两个平台合计几十万仓库，怎么收录？
**答**：**不搞全量搜索**，curated 目录。类型按 API 标签自动分类：LLM=text-generation、VLM=image-text-to-text、图像=text-to-image。

## Q8 白名单与量化范围
**问**：白名单机制？量化要不要社区版？
**答**：**量化只要官方的**（第三方/个人开发者一律不收）；**订阅制盯大厂**——定期访问白名单组织，有新模型/新官方量化就增量入库。

## Q9 订阅机制确认
**问**：白名单清单、官方量化覆盖不均、拉取频率？
**答**：白名单清单确认（见 PRD §5.1）；**接受官方量化覆盖不均**（Meta/Llama 无官方 GGUF 则该档位留空）；**每日拉取一次**。

## Q10 模型格式规则
**问**：能否用"safetensors=原版、GGUF=量化"的简单规则？
**答**：**可以**（纠正：格式名是 Safetensors 不是 SavedModel）。兜底：用 `file_size ÷ params` 反推实际字节/参数（≈2=fp16、≈1=fp8/int8、≈0.5=int4）自动纠正精度，ModelScope 直接提供这两个字段。

## Q11 技术栈
**问**：前后端框架、数据库？
**答**：**pnpm monorepo ｜ 前端 React + Vite + TS ｜ 后端 Node + TS + Fastify ｜ SQLite**（访问量起来再迁大库）｜ node-cron 定时任务。

## Q12 4 档分级逻辑
**问**：什么算能跑/勉强/流畅？
**答**：两步判定——先 VRAM 硬约束（放不下=红），再速度分档（LLM：流畅>20 tok/s、可以 5~20、勉强 2~5、太慢<2；图像：<10s / 10~30s / 30~60s / >60s 每张）；**显存余量<1GB 标勉强**；列表页用 **Q4_K_M 档**分级显示；网站内设**分档说明区**（量化定义 + 颜色图例，主体用颜色直观判断）。

## Q13 页面结构
**问**：页面怎么组织？
**答**：四页——**首页**（硬件选择器 + 类型 tab + 模型列表）、**模型详情页**（量化档位表 + 上下文滑块 + 放不下时给换卡建议）、**硬件页**（GPU 规格表）、**分档说明页**。硬件选择：**下拉选 GPU + 自定义 VRAM 兜底**。整体样式风格交由设计软件另行设计。

## Q14 界面语言与命名
**问**：语言？名字？
**答**：**中英双语 i18n 预留，一期只启用中文**；仓库名 **Can I Deploy**；域名以后决定。
